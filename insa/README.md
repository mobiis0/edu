# 인사관리 1차 목업

경영기획 담당자가 약 40명의 직원 정보를 관리하는 화면의 검토용 구현입니다. 예시 직원 12명을 사용하며 실제 개인정보는 포함하지 않습니다.

## 구현
- 이름·직급·입사년도 검색, 부서·직급·입사년도 복합 필터
- 직원 등록 및 비고 변경의 메모리 내 시험 (새로고침 시 초기화)
- 근로·연봉계약서 PDF/이미지 로컬 뷰어, 다운로드 및 새 창 인쇄
- 인사기록카드 공통 레이아웃 및 인쇄
- 제출서류 목록, 노트북 정보 화면
- 인사카드 제출 요청, 교육 안내, Office 계정 안내 메일 미리보기
- Office 미지급/지급 완료만 표시 (회수 상태 없음)

## 아직 연결되지 않은 기능
실제 메일 전송, 직원 전용 제출 링크, 공유 파일·데이터 저장, 엑셀 변환, AI 사용내역 조회, 교육명단 등록 및 이수현황/알림 연동, 경영기획 계정 인증 및 서버 권한 검사.

이 공개 Pages 주소는 목업 열람용입니다. 실제 직원 자료는 공개 Git 저장소에 저장하지 않습니다. 운영 전 경영기획 허용 계정 인증, 비공개 저장소, 서버에서 직원별 문서 접근 검사, 실제 발송 성공 처리 및 중복 방지를 구현해야 합니다. Office 초기 비밀번호는 표나 브라우저 영구 저장소에 보관하지 않습니다.

교육·AI 기존 페이지와 실제 자료 연결은 각 자료 구조 및 설정을 확인한 뒤 구현합니다. 상대 링크는 동일 edu 저장소 기준입니다.
